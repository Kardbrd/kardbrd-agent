# v0.13.2

An owned card worktree on a different branch or detached HEAD now reaches the
AI executor. Previously, lifecycle verification rejected it with an unexpected
branch error before the AI could inspect or recover the checkout.

Mentions, exact commands, and automation now include the expected branch and
actual checkout state in the AI prompt. The agent leaves branches and local
edits in place and lets the executor decide how to proceed. The recorded branch
remains available as recovery context on subsequent runs.

Path, repository, card ownership, and lifecycle preparation checks still apply.
Initial administrative adoption continues to verify the declared branch.
